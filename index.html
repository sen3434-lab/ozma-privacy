개인정보처리방침 (ozma-youtube-upload)

시행일: 2026년 11월 22일

ozma-youtube-upload는 "오즈마 샘"이 운영하는 유튜브 채널에 직접 만든 영상을 올리기 위한 개인용 도구입니다. 일반 사용자에게 제공하는 서비스가 아닙니다.

1. 사용하는 정보

채널 운영자 본인이 허용한 유튜브 계정 권한(영상 업로드, 채널의 영상 목록 확인)만 사용합니다. 다른 사람의 개인정보는 수집하지 않습니다.

2. 보관

로그인 열쇠(토큰)는 운영자 본인의 컴퓨터에만 저장되며, 외부로 보내거나 다른 사람과 공유하지 않습니다.

3. 제3자 제공

어떤 정보도 판매하거나 제3자에게 제공하지 않습니다. 이 도구는 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

4. 권한 해제

Google 계정의 보안 설정(https://myaccount.google.com/permissions)에서 언제든 접근 권한을 해제할 수 있습니다.

Privacy Policy (ozma-youtube-upload)

ozma-youtube-upload is a personal tool used only by the channel owner to upload their own videos to their own YouTube channels. It does not collect data from anyone else. Access tokens are stored only on the owner's computer and are never shared or sold. The tool complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions.
